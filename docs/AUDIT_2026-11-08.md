# Project audit (2026-11-08)

Scope: the Core Design System 2.0 master (live pages, components, classes, CMS, custom code) and the `mayes-core` repo, after Core v2.0.0, the slot-free Page Shell and the finished 404 page.

**Checked live:** Home, Services, Contact, Privacy and 404, at 390px and 1280px.

**What works:** every page has the Page Shell with one header, footer, bottom nav, set of sheets and data layer. Other things that check out:
- Sheets open, close and scroll, and their padding comes from the panel.
- The active tab and active nav link are styled.
- The Get a quote, Call, Directions and hours links are filled in.
- There's one JSON-LD block per page.
- There's no sideways scroll at either width.
- The 404 page returns a 404 status and has its own heading and buttons.
- The repo's 130 browser checks and `check.sh` pass.

## 1. Fix before the first client site

| # | Finding | Fix |
|---|---|---|
| 1 | **The forms aren't styled.** The Contact and Quote forms use Webflow's default inputs (`w-input`) and its default blue submit button (`w-button`), and the placeholders read "Example Text". The master already has `form-field`, `form-label`, `form-input` (and `is-textarea`) and `button` classes. | Apply those classes and give each field a real placeholder or none. |
| 2 | **GSAP loads twice.** Site custom code loads GSAP 3.13 and ScrollTrigger from jsDelivr, and Webflow also loads its own GSAP 3.15 and ScrollTrigger for Interactions. The custom-code copies are redundant. | Remove both GSAP lines from the head. Core's sheet animation uses whichever `window.gsap` is present. |
| 3 | **The privacy policy has no headings.** Every line of Section / Legal Text is a paragraph, so "Who we are", "What we collect" and the other headings read as body text. | Make the section titles H2 or H3 in the rich text. |
| 4 | **The Home hero image is empty.** The Image prop has no asset, so phones show a broken-image box. | Set a neutral placeholder image as the prop default, or hide the image when it's empty. |
| 5 | **SEO and sharing basics are missing.** Home has no SEO title (it shows the site name) and no meta description. No page has an Open Graph image. The favicon is Webflow's default. | Set Home's title and description, add a default share image under Site settings › SEO / Open Graph, and upload a favicon. Add all three to the per-client checklist. |
| 6 | **The Book tab ignores Booking URL.** The Business Settings field says it sets where the Book / Get a Quote buttons go, but the Book tab is hard-wired to `/contact`. | Put `data-business-href="booking-url"` on the Book tab (Core fills it when set and leaves `/contact` when empty), or delete the field. |
